## 💡 **How It Works**

### User Action Flow
```
User Click "Add Node"
    ↓
React Component (CanvasDemo)
    ↓
useCanvas Hook
    ↓
window.electron.canvas.createNode()
    ↓
Preload Bridge
    ↓
ipcRenderer.invoke()
    ↓
Electron Main (main.ts)
    ↓
IPC Handler processes request
    ↓
Returns result to React
    ↓
Component re-renders
    ↓
✅ Node appears in UI
```
